# perplexity-dnd-translator
퍼플렉시티 api이용한 던전앤드래곤 번역기
Perplexity D&D Translator

Perplexity AI API를 사용하여 Foundry VTT D&D 5e 시스템을 한국어로 번역해주는 모듈입니다.

## 기능 (Features)
- **Ctrl + L**: 선택한 텍스트를 채팅창에 번역하여 출력
- **Shift + L**: 선택한 텍스트를 팝업창에 번역 (복사 가능)
- **Ctrl + J**: 저널을 선택하여 번역
- **저널 번역**: 저널 시트 상단의 버튼이나 디렉토리의 아이콘을 눌러 전체 번역

## 설치 방법 (Installation)
Foundry VTT 모듈 설치 화면에서 `Perplexity D&D Translator`를 검색하세요.

## 설정 (Setup)
모듈 설정에서 본인의 Perplexity API Key를 입력해야 작동합니다.
